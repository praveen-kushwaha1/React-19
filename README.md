# React Practical Learning

A PR-wise React 19 learning repository based on the supplied Hindi YouTube playlist.

## Stack
- React 19
- Vite
- JavaScript
- npm
- Git and GitHub

## Prerequisites
- Node.js 22 LTS (or another version supported by the installed Vite release)
- npm
- Git
- VS Code or IntelliJ IDEA

## Run locally
```bash
cd react-learning
npm install
npm run dev
```

## Learning workflow
1. Watch the mapped playlist lecture.
2. Implement the topic locally.
3. Run and test the app.
4. Update the matching file under `PR-Notes/`.
5. Commit on a feature branch.
6. Push and open a Pull Request into `main`.
7. Merge only after checking the changes.

See `docs/roadmap.md` for the playlist-to-PR plan.
