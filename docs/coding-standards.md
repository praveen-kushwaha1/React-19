# Coding Standards

- Use functional React components.
- Use JavaScript for the initial course.
- Prefer clear, descriptive names.
- Keep components focused and reusable.
- Use one component per file when practical.
- Keep API calls in `src/services/` when that topic is introduced.
- Do not add a dependency unless the current PR needs it.
- Test the feature locally before committing.
- Do not commit `node_modules`, `.env` files, or build output.
